## 🚀 Featured Project — NEXO-MANAGER

**NEXO-MANAGER** is my local-first AI assistant runtime project. It connects a local LLM with Telegram, controlled tools, SQLite/semantic memory, security and permission gates, planning, health checks, CI, and safe deployment/rollback workflows.

**Core idea:** the model reasons, the backend controls, policy authorizes, registered tools execute, and runtime evidence verifies.
